# Tablet Detection

- Модель: YOLO26n
- Классы: `tablet`, `capsule`
- Веса: `best.pt`
- Скрипт предсказания: `predict.py`

# Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить модель на изображении:

```bash
python predict.py test.jpg
```

Изменить порог уверенности:

```bash
python predict.py test.jpg --conf 0.5
```

## 24.10.2026 — Исходная точка (v1)
* **Датасет:** Первый небольшой датасет на 61 фото (снимали на руках и на столе). В разметке было два класса: `tablet` (324 шт.) и `capsule` (59 шт.).
* **Модель:** YOLO26n.
* **Эксперименты:**
  * Учил в Colab на Tesla T4 (50 эпох): получил mAP50 = 0.968, mAP50-95 = 0.773.
  * Учил локально: mAP50 = 0.957.
* **Итог:** Модель научилась отличать капсулы от таблеток в бытовых условиях, но 61 фото — это слишком мало для жизни. Решил расширять данные.


## 25.10.2026 — Эксперименты с дообучением на MEDISEG и стабилизация детектора (v2–v4)
- **Что делал:** 
  Попытался расширить обучающую выборку открытым датасетом MEDISEG (https://city.figshare.com/articles/dataset/MEDISEG/28574786/1?file=52926545) (папка `3pills` — 2333 фото таблеток в пластиковых дозаторах). Сконвертировал COCO-разметку в YOLO и дообучил базовую модель на локальной RTX 4060 Ti.
- **С чем столкнулся:**
  Новый датасет оказался слишком большим по сравнению с исходным, и из-за этого модель переобучилась на специфичный фон дозаторов и стала «забывать» обычные таблетки на руках и капсулы[cite: 9]. Чтобы не перегружать сеть, взял из MEDISEG небольшую подвыборку (150 фото) и объединил её с исходными данными — так получился сбалансированный `merged_dataset`.
- **Итог:**
  Откатил веса к чистым базовым и дообучил модель на объединённом наборе. Порядок классов выровняли: теперь капсулы распознаются как `capsule`, а таблетки — как `tablet`. Рабочие веса перенёс в корень проекта как `best.pt`.


  ## 26.10.2026 — Версия v5: Подключение Roboflow и финальная стабилизация детектора
- **Что сделано:**
  - Скачаны и очищены открытые датасеты с Roboflow (`mangosteen` и `seblful`).
  - Нормализован маппинг классов (`0: capsule`, `1: tablet`) и исключены дубликаты.
  - Собран сбалансированный `dataset_v5_balanced`: все 61 фото из `dataset1`, 150 фото из `MEDISEG` и 300 фото из `Roboflow` (акцент на вытянутые и разноцветные капсулы).
  - Модель обучена на локальной RTX 4060 Ti (40 эпох, `batch=8`, `workers=0`).
- **Результаты стресс-теста на 16 разнородных фото:**
  - Полное устранение Domain Shift: пальцы, складки кожи и надписи на упаковках не вызывают ложных срабатываний.
  - 100% точность поиска в сложных сценах (тарелки с россыпью до 28 объектов, ячейки дозаторов, блистеры).
  - Итоговые веса зафиксированы в корне репозитория как `best.pt`.

## Инфраструктура и инструменты
- **Скрипт предсказания (`predict.py`):**
  - Переписал под CLI: принимает путь к любому внешнему изображению.
  - Возвращает форматированный JSON (`image`, `class`, `confidence`, `bbox`).
  - Флаг `--save` сохраняет читаемые рамки в `runs/detect/annotated_<имя>.jpg` независимо от разрешения исходного снимка.
- **Реестр датасетов:**
  1. `dataset1` (собственный) — 61 фото (ладонь, стол). Классы: `0: capsule`, `1: tablet`. Базовый исходный набор.
  2. `MEDISEG (3pills)` — открытый набор. 2333 фото таблеток в пластиковых дозаторах, сконвертирован в формат YOLO (`mediseg_yolo`).
  3. `merged_dataset` (объединённый) — сбалансированная рабочая выборка (61 фото `dataset1` + 150 фото `MEDISEG`). Классы: `0: capsule`, `1: tablet`. Используется для обучения текущей модели `v4`.
  4. `Pills Detection (mangosteen & seblful)` — открытые датасеты с Roboflow Universe.
  5. `dataset_v5_balanced` (финальный мультидоменный) — итоговый сбалансированный датасет (~511 фото): все 61 фото `dataset1` + 150 фото `MEDISEG` + 300 отобранных фото из `roboflow_clean` (250 train, 50 val) с упором на ракурсы капсул. Классы: `0: capsule`, `1: tablet`. Используется для актуальной модели `v5`.
