# Tablet Detection

- Модель: YOLO26n
- Классы: `tablet`, `capsule`
- Веса: `best.pt`
- Скрипт предсказания: `predict.py`

# Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить модель на изображении:

```bash
python predict.py test.jpg
```

Изменить порог уверенности:

```bash
python predict.py test.jpg --conf 0.5
```
